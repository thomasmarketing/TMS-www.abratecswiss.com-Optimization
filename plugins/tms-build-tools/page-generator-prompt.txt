==================================================

When:

Title Only

Whole Box

When Whole Box is required, use a valid semantic DOM structure that makes the actual content/link relationship clickable without an absolute-positioned overlay anchor. Prefer a single anchor containing the appropriate non-interactive card content when valid HTML permits it, or use another semantic structure that does not create nested anchors or an invisible overlay link.

The link itself must participate normally in document flow.

Choose a semantic DOM structure that remains valid HTML.
